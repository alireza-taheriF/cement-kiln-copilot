# Demo dataset (`demo_signals.csv`)

This is a **small, synthetic, demo-only** dataset used to run the
cement-kiln-copilot end-to-end without access to a real plant historian.

> ⚠️ **Synthetic & advisory-only.** These values are generated by a
> deterministic formula, not measured from real equipment. They exist purely to
> make the prediction and recommendation demo runnable and reproducible. Do
> **not** use them for engineering decisions.

## Format

Long / tidy format, one row per `(timestamp, tag)`:

| column      | meaning                                  |
| ----------- | ---------------------------------------- |
| `timestamp` | ISO-8601 sample time (1-minute spacing)  |
| `tag_name`  | signal/tag identifier                    |
| `value`     | numeric reading for that tag at that time |

## Tags included

| tag                | description (illustrative)          | approx. baseline |
| ------------------ | ----------------------------------- | ---------------- |
| `KILN_ZONE1_TEMP`  | burning-zone 1 temperature (°C)     | ~1380            |
| `KILN_ZONE2_TEMP`  | burning-zone 2 temperature (°C)     | ~1320            |
| `KILN_FUEL_FLOW`   | kiln fuel flow rate                 | ~42              |

Each tag has 90 samples (1-minute cadence), which is enough rows for the
configured lag/rolling features and forecast horizon to produce a usable
supervised dataset.

## How it is used

`scripts/train_demo_model.sh` seeds this CSV into the database (using the
ingestion layer) and then trains the model defined in
`config/model_config.yaml`, whose `target_tag` is `KILN_ZONE1_TEMP`.

To regenerate or extend the data, edit `scripts/train_demo_model.sh`'s seeding
step or replace this CSV with your own long-format export using the same three
columns.
